> 阶段定位：官网建设第二步——把现有素材整理成可直接用于设计与开发的页面内容。

## 1. 本版结论

现有素材已经足以完成一个内容完整的官网首版，不需要继续按照旧清单逐项“凑素材”。首版可直接覆盖：

- 首页、产品与解决方案、案例、关于我们、联系我们五个一级页面；
- X-IL、REAL CAR、SRIF 三条产品线；
- 14 个产品模块，其中 13 个已有可用主图，1 个暂以同系列视觉替代；
- 11 个案例卡片及案例总览；
- 公司品牌、办公环境、团队、荣誉、公众号及一条 REAL CAR 宣传视频。

仍应保留资产清单，但它不再是一份要求 Carl 找素材的“任务书”，而是一张精简的“素材—页面映射表”，只回答三个问题：素材是什么、放在哪里、上线前是否需要确认。

## 3. 网站风格与视觉系统

### 3.1 设计方向

整体气质定义为：**专业、理性、清晰、工程化，同时保留智能运载的速度感。**

参考 H3C 官网的是企业级网站的信息组织方式：宽屏首图、清晰的大标题层级、模块化产品入口、产品与案例互相导流、充足留白，以及克制的过渡动效。西部智车不照搬 H3C 的品牌蓝，而是以公司 Logo 青色为视觉核心。

参考页面：

- H3C 中文官网：https://www.h3c.com/cn/
- H3C 产品与解决方案信息组织：https://www.h3c.com/cn/Products_And_Solution/

### 3.3 字体与层级

中文优先使用 `HarmonyOS Sans SC / 思源黑体 / 苹方`，英文与数字使用 `Inter / Arial`。不使用装饰性科技字体。

| 层级 | 桌面端 | 移动端 | 用法 |
| --- | --- | --- | --- |
| H1 | 56–64 px / 1.15 | 36–40 px | 首页首屏主标题 |
| H2 | 38–44 px / 1.25 | 28–32 px | 页面大区块标题 |
| H3 | 26–30 px / 1.35 | 22–24 px | 产品系列、详情模块 |
| 卡片标题 | 20–22 px | 18–20 px | 产品、案例卡片 |
| 正文 | 16–18 px / 1.75 | 15–16 px / 1.7 | 说明文字 |
| 辅助信息 | 13–14 px | 12–13 px | 标签、时间、图注 |

### 3.4 栅格、留白与组件

- 内容最大宽度：1280 px；正文阅读宽度：760–880 px；12 栏栅格。
- 桌面端区块上下留白：96–120 px；移动端：56–72 px。
- 卡片圆角：2–6 px，避免互联网消费品牌式大圆角。
- 阴影只用于悬停：`0 12px 36px rgba(13,43,69,.12)`。
- 默认卡片用浅色分隔线，不给每一块内容套厚重边框。
- 图标采用统一线性图标，线宽 1.5–2 px；不混用 3D 图标与彩色插画。

### 3.5 图片语言

- 首页和关于页使用真实公司、真实车辆、真实实验环境，突出可信度。
- 产品页主图优先使用设备全景或实车，系统框图作为第二视觉层。
- 图片统一以冷色调校色，减少偏黄；青色仅作为图形覆盖和标签，不给照片大面积染色。
- 卡片图比例统一：产品 4:3 或 3:4；案例 16:9；首页大图区块 16:9。
- 不在图片上堆大段文字，文字由网页排版承载。

### 3.6 动效原则

- 首屏文字与按钮淡入上移 16–24 px，时长 500–700 ms。
- 产品卡片悬停仅做图片放大 1.03、青色线条出现和箭头位移。
- 三条产品线切换使用 200–300 ms 淡入，不做复杂 3D 旋转。
- 数字、流程线、案例列表可做滚动触发，但必须允许减少动态效果。

### 8.2 X-IL 六个模块

#### 整车在环模块

**一句话价值：** 将真实整车接入虚拟道路与动力学环境，在实验室内完成整车级闭环验证。  
**概述：** 以真实被测车辆为核心，将道路行驶模拟平台、车辆动力学模型和高保真场景仿真接入闭环，可开展动力、三电、智能驾驶及网联通信等整车级功能与性能验证，并按需求扩展环境模拟能力。  
**系统构成：** 整车负载模拟 / 动力学实时仿真 / 智驾实时仿真 / 环境模拟（可选）。  
**支持任务：** 功能与故障场景、城市与高速场景复现、人机交互、新能源热管理与能耗、网联智驾通信。  
**素材：** `IMG-XIL-整车在环模块.png`。

#### 智驾在环模块
