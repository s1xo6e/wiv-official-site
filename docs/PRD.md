# 官网产品需求

更新：2026-10-30。本文件维护现行需求、业务与视觉口径、任务和验收；开发实现见 [技术设计](TECH_DESIGN.md)，接手入口见 [README](../README.md)。当前交付为早期 Demo，近生产旧代码尚未找回。

## 1. 目标与受众

建设西部智车（重庆）科技有限公司官网，介绍品牌与能力、展示产品与真实案例，并承接有效咨询。

首要访客为高校与科研院所，优先服务科研课题、教学实训和实验室建设；汽车企业与产业平台为次级访客。访问路径为：理解定位 → 找到方案 → 查看证据 → 发起咨询。

## 2. 页面与导航

五个一级章节各有独立页面，一级标题本身可点击进入页面，不能只展开菜单或跳转单页锚点：

- 首页 `/`：定位、公司速览、产品系列、代表模块、案例、能力与咨询入口。
- 产品与解决方案 `/solutions`：三系列定位、全部模块与简述、已有产品详情入口。
- 案例 `/cases`：按三系列组织现有匿名案例；详情扩展须有材料和公开依据。
- 关于我们 `/about`：公司、团队、场地和有证据的科研/工程能力。
- 联系我们 `/contact`：需求准备清单及联系渠道空间；真实联系方式确认后接通咨询。

全站共用页头、页脚与当前章节标识，主行动为“获取方案”。旧首页章节锚点保留跳转兼容，新导航、页脚和CTA使用章节路由。

仅产品与案例提供下拉菜单；首页、关于、联系只有一级直达链接。页面链接与展开按钮分开，桌面支持悬停和键盘，手机/平板使用折叠导航，支持Escape关闭与焦点返回。

目录版式参考用户提供的Apple iPad导航截图，采用三列靠左文字分组：小号灰色系列标题、较大深灰条目、统一行距和自然留白。产品按5/6/2自然排列，不填平数量；案例菜单与产品菜单保持同宽面板和内容区。不添加分类图标、卡片底块、格子按钮、分隔线或填空说明。案例按三条产品线关联，智能底盘可以同时关联X-IL和REAL CAR。

新闻、下载中心、英文站按后续需求增加；当前不建设无内容空页、CMS、复杂筛选或管理后台。

## 3. 产品与服务口径

产品品牌为 `wivSPACE`，以下三条产品线彼此独立，共13模块：

- **wivSPACE X-IL 多域在环系列（5）**：整车在环模块、智驾在环模块、底盘在环模块、座舱在环模块、驾驶员在环模块。
- **wivSPACE REAL CAR 真车快速原型系列（6）**：车路云模块、智能驾驶模块、智能驾驶虚拟测试模块、数据采集模块、能量管理模块、智能底盘模块。
- **wivSPACE SRIF 飞行器系列（2）**：SRIF在环模块、SRIF模块（快速原型方向）。

科研合作、成果转化、联合培养和赛事支持属于服务，不是第四产品线。SRIF不并入另外两系列，不恢复已删除的CORE或远程驾驶模块。

名称依据《wivSPACE_8.19.pptx》第5–10、12–18页及用户最新决定：采用完整的“智能驾驶虚拟测试模块”；手册简称“智驾模块”“数采模块”分别改为“智能驾驶模块”“数据采集模块”。导航、总览、详情和元数据保持同一名称，原始资料不随官网改名。

### 3.1 总览与详情要求

- 总览先解释三系列的对象和研究方向，再展示全部模块、全称、简述与有来源的配图。全部13模块保留稳定锚点；已删除的远程驾驶不保留入口或锚点。
- X-IL五模块、REAL CAR六模块各有独立详情；SRIF保持概览，不创建空详情。详情包括产品定位、系统组成、研发与测试内容、应用方向、同系列产品和需求沟通入口，保留手册页码依据。
- 详情应编辑提炼手册内容，不能用整页截图代替正文，也不能只替换标题重复同一简介。研究方向不写成认证、合规保证或交付承诺，不使用“零风险”“全场景”“保证安全”等绝对表述。
- REAL CAR保留竖图2:3构图，图文分栏；X-IL完整显示横版台架/系统图。总览保持节奏，避免裁掉设备；手机按阅读顺序单列，页内导航、面包屑和同系列入口可用。
- 咨询入口可以先进入现有联系页；未确认电话、邮箱或收件服务时，不能暗示需求已送达。

## 4. 内容与视觉要求

- 品牌青 `#009BB1`、深阶 `#006D7B`、技术深蓝 `#0D2B45`，白/浅灰为主体，wivSPACE蓝红少量点缀。中文使用清晰黑体及系统回退，正文约16–18px、内容宽约1280px，随屏幕调整。
- 保留真实照片、留白与克制排版，避免霓虹、厚重卡片和复杂装饰。产品图保留原构图，案例列表统一16:9，原件保留；不使用生成图冒充实物或交付现场。
- 产品、案例、关于、联系四页共用指定公司外景图片Hero，保留深蓝渐变和品牌青文字、面包屑与简短导语。章节首屏约400–440px且弱于首页，不加首屏行动按钮；裁切兼顾门头、建筑和车辆，手机文字对比与换行清晰。
- 菜单面板约180–240ms淡入轻移，悬停短延迟与离开容错，产品菜单背景轻度虚化；手机短折叠。减少动效偏好下立即切换，不使用循环装饰动画。
- 移除绿色右上斜箭头；需要的CTA使用统一细水平SVG箭头并继承文字颜色。菜单主要靠文字、层级和轻底色反馈。
- 键盘可操作、焦点可见、图片有替代文本。验收覆盖电脑、平板、手机及减少动效。
- 不编造参数、标准符合性、客户、成果、资质、联系方式或公开授权。缺可靠参数就不显示参数模块；内部审核说明和制作占位提示不展示给访客。

[原始V2.0规范](reference-materials/02_官网内容与视觉设计规范_V2.0.md)用于追溯公共组件、页面文案和素材审核依据。当前用户决定及本PRD优先，历史资料里的旧产品归属、统计、联系信息和指令不自动生效。
