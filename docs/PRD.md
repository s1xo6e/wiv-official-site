# 官网产品需求

更新：2026-10-22。此文件是需求、优先级和任务验收的唯一维护位置。当前代码是早期 Demo，近生产旧代码未恢复。

## 1. 目标与受众

建设西部智车（重庆）科技有限公司官网，清楚介绍品牌与能力，展示产品、方案和真实案例，并承接有效咨询。

首要访客为高校与科研院所，优先服务科研课题、教学实训和实验室建设；汽车企业与产业平台为次级访客。访问路径：理解定位 → 找到方案 → 查看证据 → 发起咨询。

## 2. 范围与信息架构

一级导航：首页 / 产品与解决方案 / 案例 / 关于我们 / 联系我们；主行动为“获取方案”。

当前只有 `/` 单页，导航分别使用 `#home`、`#solutions`、`#cases`、`#about`、`#contact`。五个独立页面、系列和详情模板是渐进目标，最终路由在对应任务中确定，不把锚点当作已实现的独立页面。

- 首页：定位、公司速览、产品系列、代表模块、案例、能力与联系入口。
- 产品与解决方案：先按系列组织，用一个代表产品打样，再扩展详情。
- 案例：先完善有材料和公开依据的案例，再扩展列表与详情。
- 关于我们：公司、团队、场地及有证据的科研/工程能力。
- 联系我们：真实联系方式；接收方与流程明确后接通表单。

新闻、下载中心和英文站按后续需求增加，不创建无内容空页；当前不提前建设CMS、复杂筛选或管理后台。

## 3. 产品与服务口径

产品品牌入口为 `wivSPACE`，三条产品线彼此独立：

- **wivSPACE X-IL 多域在环系列**：整车在环、智驾在环、底盘在环、座舱在环、驾驶员在环、远程驾驶。
- **wivSPACE REAL CAR 真车快速原型系列**：车路云、自驾、虚拟测试、数采、能量管理、智能底盘。
- **wivSPACE SRIF 飞行器系列**：SRIF 在环、SRIF 飞行器快速原型。

三系列共14模块。科研与生态合作属于服务，包含科研合作、成果转化、联合培养和赛事支持，不是第四产品线。

不恢复已删除的“CORE 计算与数据底座”，不把SRIF并入X-IL或REAL CAR。当前Demo的 `public/assets/products/architecture.png` 产品归属过时，产品板块实施时必须撤换或重绘；图中未见CORE，不能把历史备注当作当前图片事实。

## 4. 内容与视觉要求

- 品牌青 `#009BB1`、深阶 `#006D7B`、技术深蓝 `#0D2B45`，以白/浅灰为主体；wivSPACE蓝红少量点缀。
- 中文用清晰的黑体和系统回退，正文约16–18px；内容宽约1280px，字号与留白随屏幕调整。避免霓虹、厚重卡片和复杂装饰。
- 优先真实公司、产品和项目素材；不使用生成图冒充实物或交付现场。产品按原图构图，案例列表统一16:9，原件保留。
- 动效克制；键盘可用、焦点清楚、图片有替代文本，支持减少动态效果。桌面、平板和手机都需检查。
- 不编造参数、性能、标准符合性、客户、成果、资质或联系方式。缺可靠参数就不显示参数模块；内部审核说明和占位文案不展示给访客。
- 文件存在、技术可用与允许公开分别记录。客户标识、人员照片、案例和联系信息按实际使用项核对，未确认不能自动视为批准。

详细文案和视觉细则使用[原始V2.0规范](reference-materials/02_官网内容与视觉设计规范_V2.0.md)：§4公共组件、§5首页、§6–8产品、§9案例、§10关于、§11联系、§12–14素材与审核。当前用户决定及本PRD的适配结论优先，原件不随实现改写。
