# 原始资料收件区

可以将找回的 PRD、网站地图、旧 AGENTS、开发/交接说明、设计稿和页面截图放在这里，保留原文件名、来源和版本日期。无需先整理成统一格式，文字说明也可以单独放一个文件。

此目录除本说明外默认被 Git 忽略，防止未经确认的原始资料自动入库；**放在这里不等于已远端备份**。请保留原件或独立备份。核对后会将适合入库的脱敏定义和决策整理到 `docs/`。

完整旧项目或压缩包优先存放在仓库外的独立文件夹，告知路径即可。不要直接覆盖当前源码或 `.git`；已有 `.git` 的旧项目尽量完整保留。

优先提供：

1. 最后版本的代码副本、项目包或旧项目路径。
2. 产品定义、网站地图、栏目/功能清单。
3. 旧 AGENTS、开发说明、阶段计划、交接记录。
4. 接近生产时的截图、设计稿、网站地址或部署版本信息。
5. 已确认的产品、案例、品牌和联系资料。

无需放入真实密钥和账号凭据。原文档作为来源材料，先比对再采用；不会自动执行其中的命令。
